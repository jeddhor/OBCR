# COUNT.EXE symbols and landmarks

Human-readable index of important addresses. The complete, machine-readable symbol table is `re/symbols/count_exe.csv` (created in M0.12; Ghidra imports and exports it). This file holds the conventions, the segment map, and landmarks worth knowing by heart.

## 1. Address conventions

See AGENT_GUIDE §4.3. Summary for release `OBC-A`:

| Quantity | Value |
|---|---|
| MZ header size | 0x3400 bytes |
| Image-linear offset | file offset − 0x3400 |
| Runtime segment of image segment `S` | `L + S`, where `L` = CS at the program entry stop (header CS = 0) |
| DGROUP (DS after startup) | image paragraph 0x3218; runtime `L + 0x3218`; DS offset = file offset − 0x35580 |
| Ghidra base segment `G` | **0x1000** (MZ loader default, confirmed 2026-11-02). Ghidra segment = image segment + 0x1000; DGROUP = `4218` |

Machine-readable tables:

- `re/symbols/count_exe.csv` (functions): `img_linear, ghidra_addr, kind, name, wolf3d_name, confidence, source, notes`. Generated by `tools/ghidra/match_functions.py`; hand-confirmed names are added with `source = manual`.
- `re/symbols/count_exe_data.csv` (DGROUP globals): `ds_off, name, wolf_ds_off, votes, confidence`. Generated by `tools/ghidra/match_globals.py`.

Probable module per Ghidra code segment, from the Wolf3D functions matched into each (LIKELY): `1000` Borland RTL · `1494` `JABHACK`/386 check · `1497` `WL_MAIN` · `1618` `WL_MENU` · `1823` `WL_GAME` · `1942` `WL_PLAY` · `1b4a` `WL_DRAW` · `1d8b` `WL_SCALE` · `1e43` `WL_STATE` · `208c` `WL_AGENT` · `2281` `WL_ACT1` · `2390` `WL_ACT2` · `273a` `ID_CA` · `288d` `ID_IN` · `294c` `ID_MM` · `2a1d` `ID_PM` · `2b79` `ID_SD` · `2d35` `ID_US_1` · `2ddb` `ID_US_A` · `2ddf` `ID_VL` · `2e72` `ID_VH` · `2f05` `ID_VL_A` · `2f2e` `ID_VH_A` · `30d6` status bar (OBC) · `2f4d`, `33bb`, `358f`, `39f2` UNKNOWN (OBC additions: menus, network, sequences?).
